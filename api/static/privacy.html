Privacy Policy

Applies to: PhishingDetector web app & Chrome browser extension  ·  Last updated: April 2026

Short version: The PhishingDetector extension reads the email you are currently viewing, sends it to the PhishingDetector API for classification, and shows you the result. No email content is stored, logged, or shared. Nothing leaves your browser except the email you ask it to analyse.

1. What data is accessed

The browser extension reads the following information from the email you have open in Gmail or Outlook Web:

  • The From address and display name
  • The Subject line
  • The body text of the email

The extension does not access your inbox list, contacts, attachments, account credentials, or any other data.

2. How that data is used

The email text described above is sent as a single HTTPS request to the PhishingDetector classification API. The API:

  • Analyses the text using a locally-running machine learning model
  • Returns a risk classification, confidence score, and plain-English explanation
  • Does not store, log, or retain the email content in any database

The result is displayed as a badge inside your email client. Once the browser tab is closed the data is gone.

3. Data sharing

Email content is never sold, shared, or disclosed to any third party. The only network destination is the PhishingDetector API endpoint configured in the extension settings (default: https://rwolfe26-phishing-detector.hf.space).

4. Local storage

The extension stores one item in Chrome's chrome.storage.sync: the API endpoint URL you configure in the settings popup. This URL is synced across your Chrome profiles. No email content is ever written to local or synced storage.

5. Permissions explained

  • Host access to mail.google.com, outlook.live.com, outlook.office.com, outlook.office365.com — required to read the email content from the page in order to analyse it.
  • Host access to *.hf.space — required to send the email text to the classification API and receive the result.
  • storage — required to save your API endpoint preference across sessions.

6. Children's privacy

PhishingDetector is not directed at children under 13 and does not knowingly collect data from children.

7. Changes to this policy

If this policy changes materially, the "Last updated" date above will be revised. Continued use of the extension after a change constitutes acceptance of the updated policy.
